Use an NAI Agent Gateway lab configuration with one permitted tool and one read-only tool outside the client key’s scope.

## 01 · Check the permitted call

Invoke the permitted tool through the configured client and verify that the tool result reaches the agent.

## 02 · Check the denial

Use the same key to attempt the out-of-scope call through the supported client. Confirm the tool does not run and review available gateway audit evidence.
