Use a working chat request and a prompt that produces several lines. Run the test from the same client network as the application.

## 01 · Enable streaming

Set stream to true in the chat request and use curl --no-buffer to see events as they arrive. Use the same URL, model ID, and authorization as your known-good request.

## 02 · Verify delivery

Look for multiple response events arriving over time. If direct delivery works but the app receives one burst, compare the app’s client and proxy buffering settings.
