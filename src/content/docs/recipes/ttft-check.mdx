Use a streaming endpoint and a client timer with a monotonic clock.

## 01 · Capture the right event

Start timing immediately before sending the request. Stop at the first event that contains generated content. Skip headers and role-only events.

## 02 · Compare like for like

After warm-up, run the same prompt several times with fixed generation settings. Compare the timings and record the model, client location, and concurrency. Use the benchmark playbook before making capacity decisions.
