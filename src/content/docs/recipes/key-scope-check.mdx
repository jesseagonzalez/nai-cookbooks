Use two lab endpoints, a key scoped to one of them, and a known-good request for each endpoint.

## 01 · Establish a baseline

Run each request with a key that is permitted to access its target. Confirm both requests succeed.

## 02 · Try the scoped key

Repeat both requests with the key scoped to one endpoint. Expect success on the allowed endpoint and an access denial on the other. Record the status and request time without logging the key.
