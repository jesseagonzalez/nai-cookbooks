## What you'll build

A Kubernetes cluster with GPU worker nodes running Nutanix Enterprise AI, with the NAI dashboard reachable over HTTPS.

## Prerequisites

- A supported Kubernetes cluster (for example, Nutanix Kubernetes Platform) with admin access
- At least one worker node with a supported NVIDIA GPU
- A default storage class, plus shared (ReadWriteMany) storage for model files
- `kubectl` and `helm` installed locally
- A DNS name and TLS certificate for the NAI dashboard
- Your NAI release's install bundle or registry credentials

## Steps

<Steps>
1. **Confirm cluster access and GPU nodes.**

   ```bash
   kubectl get nodes -o wide
   kubectl get nodes -L nvidia.com/gpu.present
   ```

2. **Install the NVIDIA GPU Operator** (skip if your platform already provides it).

   ```bash
   helm repo add nvidia https://helm.ngc.nvidia.com/nvidia && helm repo update
   helm install gpu-operator nvidia/gpu-operator -n gpu-operator --create-namespace
   kubectl get pods -n gpu-operator
   ```

   Wait until all pods are `Running` or `Completed`, then confirm GPUs are advertised:

   ```bash
   kubectl describe nodes | grep -A2 "nvidia.com/gpu"
   ```

3. **Install NAI's platform prerequisites.** Your release notes list the required supporting components (for example certificate management and model-serving dependencies) and their versions. Install them in the order given.

4. **Install Nutanix Enterprise AI.**

   <Tabs>
     <TabItem label="NKP">
     On NKP, enable Nutanix Enterprise AI from the platform's application catalog for your workspace, supplying your storage class and dashboard hostname.
     </TabItem>
     <TabItem label="Helm (other Kubernetes)">
     ```bash
     # Placeholder: replace with the chart reference and values from your release
     helm install nai <nai-chart-ref> \
       -n nai-system --create-namespace \
       -f nai-values.yaml
     ```
     </TabItem>
   </Tabs>

5. **Verify the install.**

   ```bash
   kubectl get pods -n nai-system
   ```

   Browse to `https://<your-nai-host>` and sign in with the initial admin credentials from the install guide. Change the password when prompted.
</Steps>

## Check your work

- [ ] All pods in the NAI namespace are `Running`
- [ ] GPU nodes report `nvidia.com/gpu` capacity
- [ ] The dashboard loads over HTTPS and you can sign in
