A ready endpoint can still be unreachable from an application network or deny a client key. Start with a minimal request from the same network as the app.

## 01 · Separate the failure domains

Check DNS, TLS, and routing first. Next verify authorization and the exact model identifier. Compare the application request against a known-good request.

## 02 · Correlate evidence

Record when the failure occurred and compare client logs with platform health, request metrics, and relevant runtime logs. Keep prompts and credentials out of diagnostic notes.
