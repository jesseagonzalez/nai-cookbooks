Nutanix Enterprise AI 2.8 documents MCP support through Agent Gateway. Check your release, license, and endpoint configuration before following the product procedure.

## 01 · Start with one read-only tool

Pick an MCP server and expose one low-risk capability in a lab. Identify its authentication, data boundary, and expected output.

## 02 · Scope the connection

Use the release-specific procedure to configure the MCP server and connector. Assign only the capabilities needed by the API client key.

## 03 · Prove the boundary

Test an allowed tool and a tool outside the key’s scope. Confirm the allowed tool returns the expected data and the disallowed tool is blocked. Review available gateway audit evidence.

## 04 · Test missing and malformed input

Send a request without a required tool argument. Verify that the client surfaces the validation failure and that the agent can ask for the missing value.

## 05 · Verify key rotation

In the lab, switch the client to a replacement key with the same intended scope. Repeat the allow and deny checks, then verify the retired key can no longer access the connector.
