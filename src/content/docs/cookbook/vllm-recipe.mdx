An upstream vLLM recipe helps identify model prerequisites, hardware constraints, and useful runtime arguments. NAI manages endpoint creation and runtime configuration through its own supported workflows.

## 01 · Capture the recipe inputs

Write down the model revision, precision, context length, hardware, runtime version, and required launch arguments.

## 02 · Map the settings

Check the supported model catalog and runtime for your NAI release. If using custom vLLM settings, follow the documented workflow for experimental endpoints and confirm every argument.

## 03 · Validate before promotion

Check startup, run the same prompt suite against the baseline and candidate, and compare latency, output quality, and resource use.
