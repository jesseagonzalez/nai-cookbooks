In a self-managed vLLM Production Stack lab on GPU-enabled Kubernetes, compare round-robin routing with a KV-aware policy. Route only among replicas serving the same model and compatible cache configuration.

## 01 · Build a baseline

Start two identical serving replicas. Pin the model and tokenizer revisions, chat template, and cache configuration. Record queue depth, time to first token (TTFT), errors, and completions per second under round robin.

## 02 · Enable cache-aware routing

Follow the upstream tutorial for your chart release. Verify each replica has a distinct instance ID where the chart requires one, and confirm the router receives cache membership or hit signals.

## 03 · Replay a controlled workload

Warm a long shared prefix on one replica. Replay requests with the same prefix and different suffixes, plus unrelated controls. Inspect the selected replica and cache reuse. Compare p95 TTFT under the same concurrency.

## 04 · Exercise eviction and saturation

Repeat after eviction or replica restart. Confirm the router stops preferring stale cache entries. Load the warm replica and check whether routing to an eligible idle replica beats waiting for a cache hit.
