Nutanix documents AI-optimized system-defined VM profiles for supported GPU-dense configurations. This lab follows the NCI 7.6 and AHV 11.2 reference. Check the profile catalog and supported configuration for your exact release and hardware.

## 01 · Match the workload to a profile

Record the required GPU count, NIC type and fabric, vCPU and memory shape, and locality needs. Compare them with system-defined AI profiles available on the target cluster. For example, Nutanix documents ai.large.b200.8gpu.cx7_ib for its B200 and ConnectX-7 InfiniBand test environment.

## 02 · Deploy from the system-defined profile

In Prism Central, use the release-specific VM creation workflow to select the supported AI-optimized profile and provision a lab guest. Attach the appropriate boot image and networks using the cluster’s documented workflow. Verify placement succeeds before installing the guest stack.

## 03 · Inspect guest topology

Run nvidia-smi -L and nvidia-smi topo -m in the guest. Inspect CPU and memory locality with numactl --hardware where available. Compare the reported GPU and NIC relationships and NUMA layout with the selected profile.

## 04 · Validate data movement

Use the appropriate NCCL or RDMA lab test for your configuration. Record GPU and NIC visibility, collective bandwidth and error counts, then run an inference smoke test before adding the guest to an NKP worker pool.

## 05 · Diagnose a placement failure

Check host eligibility, free device inventory, fabric mode, and whether the required topology fits on an eligible host. Reconcile the profile and available capacity before retrying.
