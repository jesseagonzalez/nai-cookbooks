A model contains learned weights. An inference runtime loads those weights and handles requests. Nutanix Enterprise AI (NAI) helps teams deploy and manage model-serving endpoints on supported Kubernetes infrastructure.

## 01 · Follow the request

A client sends a prompt to an endpoint with a client key. The serving stack validates access, runs inference, and returns generated text.

## 02 · Choose a learning path

Platform operators prepare the environment and publish endpoints. Application developers connect clients and verify output. AI engineers measure quality and performance under representative traffic.
