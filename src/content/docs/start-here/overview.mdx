**Nutanix Enterprise AI (NAI)** lets you run large language models and other generative AI models on infrastructure you control, on premises, at the edge, or in your own cloud accounts, and expose them to applications through secure, OpenAI-compatible API endpoints.

Nutanix AI Labs teaches you how to use it, whether you have never deployed a model before or you are designing a multi-cluster AI platform.

## How the content is organized

| Format | What it's for |
| --- | --- |
| **Learn** | Explain one idea clearly. No setup required. |
| **Cookbook** | Playbooks and cookbooks: ordered steps toward a working result. |
| **Recipes** | One focused check or task, copy-paste ready. |
| **Showcase** | Interactive labs that run in your browser, plus advanced scenarios. |
| **Blog** | Field notes, deep dives, and lessons learned. |

Every page shows its **level** (Beginner, Intermediate, Advanced) and an estimated **time** under the title, so you can tell at a glance if it's for you.

<Aside type="caution" title="Always check the product docs">
  Product specifics such as supported versions, prerequisites, and UI labels change between releases. Each resource links the Nutanix references it was written against. When in doubt, the official Nutanix documentation on the Nutanix Support Portal is the source of truth.
</Aside>
